## TASK

"Slice and send": two MCP tools so Claude can turn an STL into G-code with Marcel's PrusaSlicer presets,
report time/grams/cost, and upload the file to the printer. **No tool starts a print** (safety: bed may
not be clear — Marcel presses start on the printer).

1. `slice_model(model_path, printer_profile, print_profile, material_profile, output_dir=None)`
2. `upload_gcode(gcode_path, overwrite=False)`

## DESIGN (decided by Claude)

- New module `slicer.py`: `build_command(...) -> list[str]` (pure), `parse_gcode_stats(path) -> dict`
  (pure), `async slice_model(...)` running the CLI via `asyncio.create_subprocess_exec` (list args,
  **never** `shell=True`), timeout 600 s.
- Executable path from env `PRUSA_SLICER_PATH`, default the path above. Missing exe → clear error.
- **Force ASCII G-code** (`.gcode`) so stats can be parsed; the MK4 profile may default to binary.
  Find the right override (e.g. `--binary-gcode 0` or `--no-binary-gcode`) by running the real CLI's
  `--help-fff` and one real slice in a temp dir; state in the result which one works.
- `parse_gcode_stats` reads PrusaSlicer's trailing comments: `; filament used [g] = …`,
  `; estimated printing time (normal mode) = 1h 2m 3s` (→ seconds), `; filament_type = …`.
  Missing values → `None`, not an error.
- `slice_model` returns `{gcode_path, print_time_s, filament_g, filament_type, cost_estimate}`;
  `cost_estimate` comes from `calculate_cost` using material + grams + time (skip if grams/time missing).
- `PrusaLinkClient.upload_file(storage, remote_name, data: bytes, overwrite=False)` →
  `PUT /api/v1/files/<storage>/<remote_name>` with headers `Content-Type: application/octet-stream`,
  `Overwrite: ?1|?0`, and **`Print-After-Upload: ?0` always**. (Header names from Prusa's PrusaLink
  OpenAPI — not yet checked on this printer; Claude verifies live after merge, with Marcel's OK.)
- `upload_gcode` validates: file exists, suffix `.gcode`/`.bgcode`, size > 0; uploads to `usb`
  under the file's basename; 409 (exists) → clear message suggesting `overwrite=True`.
- Errors as JSON `{"error": ...}` like the existing printer tools. Never include the API key.
